# odin-sign-up-form

A sign-up form page built with HTML and CSS for The Odin Project.

## What I practiced

- HTML forms with labels, input types, and the `required` and `minlength` attributes
- Styling inputs with `:focus` and `:user-invalid`
- Page layout with Flexbox
- Background images with `background-size: cover`
- Semi-transparent overlays with `rgba()`
